### 风险与降级策略

| 风险 | 降级方案 |
|------|---------|
| LLM 调用超时/失败 | 静默降级为现有规则分类 |
| LLM 返回格式异常 | try-catch 捕获，降级为规则分类 |
| LLM 调用成本过高 | 内容截断 2000 字；短文本（< 50 字）跳过 AI |
| GitHub API 限流 | 指数退避重试，记录 syncStatus=failed |
| ChromaDB 删除 API 不支持元数据过滤 | 记录待清理 dedupeKey 到队列 |
| 知识图谱节点爆炸 | 限制每条消息最多提取 5 个实体 |
