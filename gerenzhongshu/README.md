# 个人中枢 — IntelliConnect 二开执行入口

> 更新时间：2026-03-10
> 用途：个人中枢项目的当前主路线、待办清单和执行文档集中入口。
> 底座：IntelliConnect v1.0.5（已确认，commit `3a78d7e`）裁剪式二开。

---

## 本次开发决策

### 1. 项目主目标

- 先做个人中枢主链路，不再优先扩自动发布
- 第一优先级：微信收集、个人速记、知识归档、知识图谱、飞书和 GitHub 同步

### 2. 底座策略

- 以 IntelliConnect v1.0.5 为确认底座进行裁剪式二开
- 保留知识、记忆、配置、用户、图谱、模型接入等底座能力
- 冻结 IoT、设备、OTA、MQTT、监控等当前无关模块

### 3. 输入层策略

- 所有输入源统一走输入层，先标准化消息再进入主系统
- 不把微信协议细节直接写死到主系统业务层

### 4. 前端策略

- 后端底座尽量统一；前端按业务域拆分
- 允许"个人中枢前端 + AI 硬件服务前端"互相跳转

### 5. 部署策略

- 先收缩功能 → 跑最小闭环 → 部署收缩后的版本
- 不采用"原项目直接部署后再边跑边大改"

### 6. 上游合并策略

- 保留上游同步分支
- 新功能优先新增模块实现
- 尽量少改上游核心公共层
