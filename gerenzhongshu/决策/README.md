## 一、项目定位

个人中枢是当前重新梳理后的项目目标。

当前主目标是先跑通下面这条闭环：

- 微信信息接入
- 个人速记保存
- 信息分类整理
- 知识归档与图谱关联
- 待办提取
- 飞书与 GitHub 同步

当前不再把"自动改写、自动发布、工作流编排"作为第一优先级主链路。
